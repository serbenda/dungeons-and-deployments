# Documentación

Guías para entender, modificar y publicar Dungeons & Deployments. Si es tu primera vez en el código, léelas en este orden.

| Guía | Qué explica |
|---|---|
| [Arquitectura](arquitectura.md) | Cómo se cargan los scripts, el bucle, la máquina de estados, las coordenadas y el reparto en archivos |
| [Diseño del juego](diseno-del-juego.md) | Héroes, enemigos, jefes, secciones, objetos, puntuación y todos los números de equilibrio |
| [Gráficos](graficos.md) | El motor de pixel art, los esqueletos y las poses, la mazmorra y la iluminación |
| [Audio](audio.md) | Efectos de sonido y el secuenciador de música chiptune |
| [Controles, móvil y PWA](controles-y-movil.md) | Teclado, mandos táctiles, pantalla completa e instalación sin conexión |
| [Recetas](recetas.md) | Paso a paso para añadir enemigos, jefes, secciones, objetos, diálogos y temas |
| [Pruebas](pruebas.md) | Pruebas unitarias, prueba de humo, semillas y modo depuración |
| [Despliegue y versiones](despliegue-y-versiones.md) | CI, GitHub Pages, caché de la PWA y cómo publicar una versión |

La referencia de cada función está en el propio código: todas las funciones y tablas de datos tienen su comentario JSDoc, que los editores (VS Code y otros) muestran al pasar el ratón.

Las capturas y el GIF del README están en [`img/`](img/).
